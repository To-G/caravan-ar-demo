# 魔法集市召唤卡

独立版入口为 `magic-stickers/`。三张贴纸分别定位花店、喷泉和书店。它们的识别图案用于选择模型、确定位置和朝向。

- `index.html?ar`：打开相机扫贴纸。
- `index.html?preview`：无摄像头演示，拖动画面环看。
- `print.html`：A4 打印稿。贴纸可以剪开自由摆放，按相同尺寸打印。
- `assets/stickers.mind`：由 `flower.svg`、`fountain.svg`、`book.svg` 按顺序编译。修改识别图后需按相同顺序重编译。
- `market.js`：店铺模型、出场与粒子动画。书店和喷泉同时被识别时，纸鸟会飞向喷泉。

可先单张扫码，确认模型与图案对应，再把贴纸摆在一起测试组合。短暂丢失目标时，该贴纸的动画会暂停，重扫时恢复进度。
