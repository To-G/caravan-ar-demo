# 魔法市集窗口卡

本版使用 60 × 90 毫米竖版卡片。上方有六乘六方格地图，含固定植物、后巷小屋和三个留白建筑位，下方为标题与 Cloudflare 二维码。

- 卡片印刷稿和三张 16 × 16 毫米贴纸在同一张 A4 PDF，选择实际大小 / 100% 打印。
- 扫码后先读取卡面和贴纸，屏幕会显示 1-3 号位读到的内容。读取结果连续稳定后自动打开，无需点击。
- 可以贴 1-3 张不同的贴纸。空位不生成对应建筑。三张贴纸各一张，每种贴纸仅一份。
- 换位置后点「重新识别」。读取结果保存在本次体验中，重新打开会重新读取。
- card-layout.js 定义物理尺寸与三个建筑位置；read-stickers.js 在卡面定位后逐格读取建筑图案。
- student-card.svg 编译到 card-stickers.mind。三个建筑 SVG 用于逐格图像比对，改卡图时须重新编译卡面识别数据。
- print-a4.html 为打印预览，print-a4.pdf 为可直接打印的最终文件。
- Cloudflare 项目仅发布静态资源，不使用服务端函数或数据库。
- 默认使用后置主摄。不论是否识别到卡片，都可拍照或切换前置自拍，前后置都能读取卡片、自动打开集市并持续跟踪。
- 拍合照将相机画面与 AR 合成 JPEG，不包含操作按钮。预览后可保存、分享或长按图片保存，具体由手机浏览器支持情况决定。
- 当前平台使用单 HTML 发布，运行 `node scripts/build-single.cjs` 生成 `../output/窗口贴纸版-单HTML/index.html`。






程序优化（保持现有卡面不变）：
- 高置信度读取采用较短确认时间，普通结果保留多次确认。
- 空位使用当前卡面的真实图案匹配，模糊或越界返回未确认，不自动作为空位。
- 限制读取图像尺寸，复用画布与模板，跳过重复视频帧。
- 贴纸确定后停止重复读取，卡面持续跟踪；显示过滤根据移动幅度调整响应。

视频：短按拍照，长按约 0.4 秒开始录制，松手结束，最长 10 秒。录制为无声合成视频，浏览器支持时优先 MP4，否则 WebM。预览后保存或分享，录制期间不可切换镜头。
